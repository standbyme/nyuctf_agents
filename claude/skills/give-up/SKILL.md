# Give Up on Challenge

Use this skill only when you have:

1. Thoroughly analyzed all provided files
2. Tried multiple exploitation/analysis approaches
3. Exhausted available tools and techniques
4. Been unable to make further progress

## Before Giving Up

Ask yourself:
- Have I analyzed all the challenge files?
- Did I check for hidden data, steganography, or encoding?
- Did I try all relevant tools for this category?
- Did I search for hints in the challenge description?
- Did I try common techniques for this challenge type?
- Did I look for similar challenges or writeups?

## When to Give Up

It's reasonable to give up when:
- The challenge requires knowledge/tools you don't have
- You've hit a hard technical limitation
- The challenge appears broken or misconfigured
- You've spent significant time without any progress

## Documenting the Attempt

When giving up, document:
1. What you tried
2. What you discovered
3. Where you got stuck
4. Potential approaches you didn't try

This helps for future reference and learning.

## Usage

Only invoke this skill manually when you're certain you want to give up:

```
/give-up
```
